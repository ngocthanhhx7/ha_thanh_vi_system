# Hanoi food news implementation plan

**Goal:** Add a polished Vietnamese `/tin-tuc` page containing 20 sourced news summaries, without requiring admin authoring.

**Architecture:** Keep the selection in a typed local JSON collection. Use a lazy-loaded React page and styles scoped to `.news-page`. Reuse the existing navigation array for desktop, mobile and footer links. External publisher pages remain the full-article destinations.

**Tech stack:** React, TypeScript, React Router, CSS, Playwright; agy Gemini 3.8 High for source research and images, configured Claude CLI at max for SEO/GEO consultation.

- [x] Add and run a failing Playwright test for the new route, 20 attributed cards, search/category filtering and mobile navigation.
- [x] Research 20 distinct, relevant publisher articles through agy. Verify titles, exact URLs and publication dates; leave unknown dates null. Use original short paraphrases, not republication. Save provenance with the data.
- [x] Create original editorial illustrations for the four topic groups. Clearly identify illustration status in the page and image alt text. Keep images local and optimized.

- [x] Add an accurate collection title, description and CollectionPage/ItemList JSON-LD. Record keyword clusters and the production-domain/crawlability deployment checklist in `docs/news-editorial.md`; do not invent a domain or make SEO ranking claims.

## Constraints

No admin/backend changes, no public deployment, no edits to unrelated existing work, no fabricated sources/dates/credentials, and no model override for Claude. Images are illustrations, never represented as photographs from the linked news articles. Every card names and links its source.
